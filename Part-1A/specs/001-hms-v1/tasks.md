# Tasks: Hospital Management System (HMS) Version 1.0

**Input**: [spec.md](./spec.md), [plan.md](./plan.md), and the approved [constitution](../../.specify/memory/constitution.md)

**Organization**: Tasks are phased in the requested implementation order. Each task includes requirement traceability and explicit prerequisite task IDs. `[P]` means the task can be performed independently of other tasks in that phase once its listed prerequisites are complete; it does not mean work can bypass dependencies. Tasks are sized for one developer and deliver a verifiable increment.

**Scope guard**: This file plans Version 1.0 only. It adds no product features, states, dependencies or scope beyond the specification and plan. Do not implement rescheduling, staff appointment completion, billing, pharmacy, laboratory, EMR, insurance, video consultation, external messaging, multi-branch or AI functionality.
